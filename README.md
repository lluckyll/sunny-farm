# Sunny Farm 해바라기 농장 영어 모험

ORT(Oxford Reading Tree) 1~2단계 핵심 표현을 익히는 아이용 픽셀 농장 게임이에요.

- 플레이: https://lluckyll.github.io/sunny-farm/
- 챕터 1~4: Stage 1+ 표현 (Look at ~, This is ~, Who is it?, Here is ~, 명령문)
- 챕터 5~8: Stage 2 표현 (said, was, went to, got, had, I like ~)
- 말하기 채점: 브라우저 음성 인식 사용 (크롬 권장, 인터넷 연결 필요)
